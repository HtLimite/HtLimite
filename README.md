## 01 · 关于我 / About

关注企业级业务系统的工程化交付，从需求拆解、复杂表单与流程、组件设计、接口联调到部署运维。持续实践 AI 应用开发，将模型接入、知识库、工具调用和工作流转化为可验证的工程能力。

- **前端工程：** React、Vue 3、TypeScript、Umi、Vite；复杂表格、表单、权限与业务流程。
- **全栈实践：** Node.js、Spring Boot、FastAPI、PostgreSQL、MySQL、Redis。
- **AI 应用：** RAG、Agent、工具调用、工作流编排、AI 辅助研发与验证。
- **交付与多端：** Docker、Linux、Nginx、Jenkins、GitHub Actions、uni-app、Cocos Creator。
