## 关于我

日常主力做前端开发，写过不少供应链和企业级业务系统；工作之外喜欢把想到的点子做成小工具，顺带折腾后端、部署和 AI 应用。写代码常用 AI 提效，但更在意架构边界和最终跑出来的质量。

- **前端：** React、Vue 3、TypeScript、Umi、Vite（复杂表单、权限与中后台业务）
- **后端与数据：** Node.js、Spring Boot、FastAPI ｜ PostgreSQL、MySQL、Redis
- **AI 折腾：** RAG 知识库、Agent 工具调用、工作流编排、AI Coding
- **多端与部署：** uni-app、Cocos Creator ｜ Docker、Linux、Nginx、Jenkins、GitHub Actions
